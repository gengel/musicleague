What gets auto-generated per round

Always computed
  • Round winner + their score + art
  • Standings after (delta from previous)
  • Biggest mover (largest positive swing)
  • Submission count + voter count
  • Round theme from the export
Conditionally generated "moments"
  • Forfeited score that would have won/changed standings
  • Most divisive song (if spread is an outlier)
  • Lead change or tightest gap
  • Someone's first/only win
  • New "record" (highest score, most downvoted, etc.)
  • Music data hook: round's avg popularity/year, notable outlier
  • Cover/remix relationship insight (if themed round)
  • Kingmaker moment (if removing one voter changes the winner)
Each round picks 2–3 of the most interesting moments from the candidate list. No two rounds lead with the same type of moment consecutively. The algorithm ranks by statistical unusualness (z-score against the season) so genuinely notable things rise to the top.
Implementation Notes

What stays from the current build

  • Parser, scoring engine, stats model — unchanged
  • Bake CLI, redaction, art inlining, genre lookups — unchanged
  • Affinity matrix, graph, genre table — restyled but same logic
  • Superlatives — same computation, new layout (gateway links)
  • Headlines/facts — same

What's new

  • Monte Carlo simulator — samples from observed per-round distributions, 10k iterations
  • Spotify metadata fetch — popularity, year, duration (requires API key at bake time)
  • Taste bias analysis — correlations between metadata and scores
  • Player archetypes — computed from median year + avg popularity
  • Player detail view — 3 sub-tabs (submissions, votes given, votes received)
  • Song cards — browsable, filterable, with Wikipedia facts + cover info
  • Cover/original panel — relationships for themed rounds
  • Projection cone on timeline chart (grey shading for remaining rounds)
  • Gateway cards on Overview with mini-visualizations
  • Play-by-Play tab — auto-generated narrative recap per round, picking 2–3 moments by statistical unusualness
  • 6-tab structure (down from 8)
  • Player table and profiles merged into one view with selection
  • Participation folded into Players (forfeits inline)
  • Future folded into The Race (projections as the coda)
